Deployment → incident correlation — did a release cause this?

Correlation is not causation. A row marked CORRELATION ONLY means only that a production deployment happened within 7 days before the incident. CONFIRMED means a post-incident review recorded that deployment in incident.caused_by_deployment_id. The database keeps the two apart on purpose.
